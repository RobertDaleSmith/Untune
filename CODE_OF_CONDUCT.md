# Code of Conduct

This project adopts the [Contributor Covenant, v2.1][cc] as its code of
conduct. By participating in this project — issues, pull requests,
discussions, or any other space — you agree to uphold it.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## TL;DR

Be respectful. Assume good faith. Disagree on the substance, not the person.
A project this small lives or dies on a friendly community — please help keep
it that way.

## Reporting

If you witness or experience behavior that violates the Contributor Covenant,
please report it privately to **robertdalesmith@gmail.com**. Reports will be
handled confidentially and in good faith.

The maintainer reserves the right to remove comments, commits, code, issues,
or contributors that don't align with this Code of Conduct, and to ban —
temporarily or permanently — anyone for behaviors deemed inappropriate,
threatening, or harmful.
